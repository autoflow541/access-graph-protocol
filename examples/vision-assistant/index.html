AGP execution service, a different media type

What am I looking at?

The same protocol and the same server-side execution model as every other device in this repo (service/, unmodified), applied to a camera instead of a smart device. Real camera capture, real speech output. The description itself is simulated by default (see the connection banner below): start the service with ANTHROPIC_API_KEY set for a real one. Start it first: npm run service:dev:vision (defaults to http://localhost:8791, token dev-token).
